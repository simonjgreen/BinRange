# Original prototype archive

`pre-versioning-originals.zip` preserves every previous case source, export, historical README, check and distribution ZIP at its original relative path. `pre-versioning-sha256.json` records every archived file hash; all entries were verified before reorganising. These are historical records, not current printing instructions.

The unversioned `exports/case.3mf` and `exports/base.png` were not assigned a version because their provenance was not verified. No standalone v1 model was found. Duplicate aliases and small test coupons remain only in this archive. Board evidence remains under `../sources/`.
